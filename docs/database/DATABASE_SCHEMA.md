# Database Schema (3NF) for Smart Irrigation Dashboard

This document describes the **normalized relational database structure (target: PostgreSQL)** as implemented in the `app/infrastructure/models` directory.

It includes:

- **Tables + fields + types**
- **Primary keys / foreign keys**
- **Constraints + indexes**

---

## Conventions

- **Timestamps**: use `timestamptz` (store UTC).
- **IDs**: use `uuid` (generated by app or DB).
- **Soft delete**: implemented via `deleted_at timestamptz` for business entities.
- **Audit Fields**: `created_at` and `updated_at` are tracked for most tables.

---

## Core Domain Tables

### `zones`

Stores irrigation zones.

- **Columns**
  - `id uuid` **PK**
  - `name text` **NOT NULL**
  - `is_active boolean` **NOT NULL** DEFAULT `false`
  - `created_at timestamptz` **NOT NULL**
  - `updated_at timestamptz` **NOT NULL**
  - `deleted_at timestamptz` NULL

- **Indexes**
  - `idx_zones_active (is_active)`
  - `idx_zones_deleted_at (deleted_at)`

### `plants`

Plants belong to a zone.

- **Columns**
  - `id uuid` **PK**
  - `zone_id uuid` **FK → zones(id)** **NOT NULL**
  - `name text` **NOT NULL**
  - `image_url text` NULL
  - `health text` **NOT NULL** CHECK (`health in ('excellent','good','needs-attention','critical')`)
  - `created_at timestamptz` **NOT NULL**
  - `updated_at timestamptz` **NOT NULL**
  - `deleted_at timestamptz` NULL

- **Indexes**
  - `idx_plants_zone_id (zone_id)`
  - `idx_plants_deleted_at (deleted_at)`

### `sensors`

Represents physical or logical sensors.

- **Columns**
  - `id uuid` **PK**
  - `name text` **NOT NULL**
  - `type text` **NOT NULL** CHECK (`type in ('humidity','temperature','air-quality','water-level','flow')`)
  - `unit text` **NOT NULL** (e.g. `'%'`, `'°C'`, `'L/min'`)
  - `plant_id uuid` NULL **FK → plants(id)**
  - `zone_id uuid` NULL **FK → zones(id)**
  - `is_active boolean` **NOT NULL** DEFAULT `true`
  - `created_at timestamptz` **NOT NULL**
  - `updated_at timestamptz` **NOT NULL**
  - `deleted_at timestamptz` NULL

- **Constraints**
  - Parent rule (exactly one parent):
    - CHECK `((plant_id is not null) + (zone_id is not null) = 1)`

- **Indexes**
  - `idx_sensors_plant_id (plant_id)`
  - `idx_sensors_zone_id (zone_id)`
  - `idx_sensors_type (type)`
  - `idx_sensors_deleted_at (deleted_at)`

### `sensor_readings`

Time series readings for any sensor.

- **Columns**
  - `id uuid` **PK**
  - `sensor_id uuid` **FK → sensors(id)** **NOT NULL**
  - `recorded_at timestamptz` **NOT NULL** DEFAULT `now()`
  - `value double precision` **NOT NULL**

- **Constraints**
  - `unique(sensor_id, recorded_at)`

- **Indexes**
  - `idx_sensor_readings_sensor_time (sensor_id, recorded_at desc)`

## Device Management Tables

### `devices`

Physical hardware devices running the irrigation logic.

- **Columns**
  - `id uuid` **PK**
  - `hardware_id text` NULL **UNIQUE** (Physical MAC/Serial)
  - `name text` **NOT NULL**
  - `description text` NULL
  - `is_active boolean` **NOT NULL** DEFAULT `true`
  - `last_seen_at timestamptz` NULL
  - `is_online boolean` **NOT NULL** DEFAULT `false`
  - `uptime float` NULL (in seconds)
  - `created_at timestamptz` **NOT NULL**
  - `updated_at timestamptz` **NOT NULL**
  - `deleted_at timestamptz` NULL

### `device_logs`

Diagnostic logs sent by physical devices.

- **Columns**
  - `id uuid` **PK**
  - `device_id uuid` **FK → devices(id)** **NOT NULL**
  - `level text` **NOT NULL** (info, warning, error, critical)
  - `message text` **NOT NULL**
  - `recorded_at timestamptz` **NOT NULL** DEFAULT `utcnow()`
  - `created_at timestamptz` **NOT NULL**
  - `updated_at timestamptz` **NOT NULL**

- **Indexes**
  - `idx_device_logs_device_id (device_id)`
  - `idx_device_logs_level (level)`
  - `idx_device_logs_recorded_at (recorded_at)`

### `device_images`

Images captured by device cameras (plant snapshots, tank levels).

- **Columns**
  - `id uuid` **PK**
  - `device_id uuid` **FK → devices(id)** **NOT NULL**
  - `plant_id uuid` NULL **FK → plants(id)**
  - `zone_id uuid` NULL **FK → zones(id)**
  - `image_url text` **NOT NULL**
  - `type text` **NOT NULL** (plant, tank, zone)
  - `captured_at timestamptz` **NOT NULL**
  - `metadata_json text` NULL
  - `created_at timestamptz` **NOT NULL**
  - `updated_at timestamptz` **NOT NULL**

- **Indexes**
  - `idx_device_images_device_id (device_id)`
  - `idx_device_images_plant_id (plant_id)`
  - `idx_device_images_zone_id (zone_id)`
  - `idx_device_images_captured_at (captured_at)`

## Water Domain Tables
The water/tank domain tables were removed from the backend domain model.

## Irrigation Control + Activity

### `irrigation_jobs`

Tracks start/stop requests and execution status.

- **Columns**
  - `id uuid` **PK**
  - `scope text` **NOT NULL** CHECK (`scope in ('zone','plant')`)
  - `zone_id uuid` NULL **FK → zones(id)**
  - `plant_id uuid` NULL **FK → plants(id)**
  - `action text` **NOT NULL** CHECK (`action in ('start','stop')`)
  - `duration_seconds integer` NULL CHECK (`duration_seconds is null or duration_seconds > 0`)
  - `status text` **NOT NULL** CHECK (`status in ('accepted','running','completed','failed','cancelled')`)
  - `requested_at timestamptz` **NOT NULL** DEFAULT `now()`
  - `started_at timestamptz` NULL
  - `ended_at timestamptz` NULL
  - `error_message text` NULL

- **Constraints**
  - Parent rule:
    - CHECK `((zone_id is not null) + (plant_id is not null) = 1)`

- **Indexes**
  - `idx_irrigation_jobs_zone (zone_id, requested_at)`
  - `idx_irrigation_jobs_plant (plant_id, requested_at)`
  - `idx_irrigation_jobs_status (status)`

### `activity_events`

System activities and audit trail.

- **Columns**
  - `id uuid` **PK**
  - `zone_id uuid` NULL **FK → zones(id)**
  - `plant_id uuid` NULL **FK → plants(id)**
  - `sensor_id uuid` NULL **FK → sensors(id)**
  - `type text` **NOT NULL**
  - `message text` **NOT NULL**
  - `occurred_at timestamptz` **NOT NULL** DEFAULT `now()`

- **Indexes**
  - `idx_activity_zone_time (zone_id, occurred_at)`
  - `idx_activity_plant_time (plant_id, occurred_at)`
  - `idx_activity_sensor_time (sensor_id, occurred_at)`
  - `idx_activity_type (type)`
